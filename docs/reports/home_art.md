# Home furniture art (src/art/home/, ids `furn.home.<name>`) — condensed. Preview: `node tools/gallery.mjs furn.home --scale 3 --out h` (composed test rooms: `furn.home.room`).
Common params: tier 0/1/2 (default 1), colours c/c2/c3/wood/metal/top/pot/frame, seed, on (screens/stove/shower...), show (sunset news game desktop code toon static), face: 3 (chair/officechair/sofa.2/sofa.3/armchair seen from behind), len/w/d/h.
Names (function tags in brackets): bed.single/.double/.king/.bunk/.futon/.floor [bed]; kitchen.fridge [fridge], .stove [stove], .counter, .counter.corner, .cabinet (wall, mount 1.5), .sink [sink], .island, .microwave [microwave], .coffee [coffee], .clutter, .dishrack, .trash, .pantry [pantry];
chair, stool, sofa.2, sofa.3, sofa.L, armchair, beanbag, officechair [seat]; table.2/.4/.round (has `chairs: [{x,y,face}]`), coffeetable; desk [computer] (use = chair centre; chair with face:3), laptop [computer];
tv.small/.medium/.large/.wall [tv]; arcade, console [game]; stereo [music]; bookshelf [bookshelf]; easel [easel]; guitar, piano, keyboard [instrument]; yogamat, treadmill, dumbbells [exercise]; aquarium; petbed;
bath.shower [shower], bath.bathtub [bath, shower], bath.toilet [toilet], bath.sink [sink], bath.washer [laundry], bath.towelrack (wall), bath.mat; wardrobe [wardrobe], dresser, nightstand (lamp), lamp.floor, radiator (wall), fireplace, xmastree, pumpkin,

Conventions: front on +y (flip for the -x wall). `use` = floor spot ~0.35 in front; beds use the +x side. `seats: [{x,y,z,dir, lie?|stand?}]`; `seatsFor(p)` on chairs/sofas when face/bar changes them. Wall items: local z=0 at the item's bottom, `mount` = recommended height.
Countertop appliances with `base:false` sit at z .8 on counters. Place rugs/mats before furniture standing on them.
