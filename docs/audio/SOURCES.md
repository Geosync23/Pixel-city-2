# Audio sources (recordings used or tried for the city ambience, owner msgs 111-114)
All three are marked PUBLIC DOMAIN on Wikimedia Commons (checked 2026-11-15 through the Commons API, field LicenseShortName). Each loop here is a 22 s mono 44.1 kHz excerpt, loudness-normalised, with a 2 s crossfade so it loops; MP3 72 kbit/s.
- loop_street.mp3 <- https://commons.wikimedia.org/wiki/File:Sunday_in_the_city_street_noise1.ogg (from 1:00)
- loop_gulls.mp3 <- https://commons.wikimedia.org/wiki/File:Gulls_above_the_street_at_dawn.ogg (from 0:08)
- loop_beach.mp3 <- https://commons.wikimedia.org/wiki/File:On_a_pebble_beach.ogg (from 0:06)
Used so far only in the listening test page (Maple Bay Sound Test artifact), NOT in the game. Nobody on the team has heard them; the owner judges by ear.
Notes: Commons rate-limits anonymous requests hard (HTTP 429): one request every ~50 s worked. No public-domain park birdsong or night-insect recording of 15 s+ turned up in the first searches; the demo generates those.
